# 路线图

> [文档索引](../README.md) · [返回 README](../../README.md) · [English](../en/roadmap.md)

以下清单按顺序记录已交付与计划中的功能，`[x]` 表示已完成，`[ ]` 表示计划中。

- [x] 屏幕镜像
- [x] 扩展屏（虚拟显示器自动激活/分离 + 按显示器采集 + 鼠标穿越，Windows）
- [x] 直连模式（绕过 SSDP 多播）
- [x] 远程 CPU 卸载（RLE 压缩 + 色彩修正，真实耗时测量）
- [x] 扩展握手（分辨率交换）
- [x] 图形启动器（SDL2_ttf 中文界面：接收/发送/搜索/机器列表/手动 IP）
- [x] macOS CoreGraphics 采集
- [x] 远程端口检查服务（TCP 8083）
- [x] 每客户端统计 + JSON 导出
- [ ] 接收端输入回传（键鼠控制在接收端侧真实生效）
- [x] 可选编码方案：RLE / H.264 / H.265 / AV1 四种方式作为可配置项
- [x] GUI 高级设置（编码方式、连接历史管理）
- [x] 应用内检查更新 + 一键下载安装（Windows，SHA-256 校验 + 管理员专属下载目录）
- [x] 扩展分辨率选择（自动匹配接收端；`config.ini` 的 `extend_res` 可手动指定，暂未做 GUI 控件）
- [ ] 音频采集与传输
- [ ] TLS 加密
- [x] 虚拟显示器分辨率自适应接收端（连接前探测；精确模式按需写入 `vdd_settings.xml`，否则黑边适配）
- [ ] 自适应帧率
- [ ] Wayland 支持
- [ ] macOS/Linux 虚拟显示器方案
- [x] 屏幕拼接（纯软件 KVM：一套键鼠控制两台电脑，各自保留显示器；Windows ↔ Windows）
- [x] 连接授权（允许任意 / 仅密码 / 每次手动授权，默认手动；8081/8084 同一策略，8082/8083 会话令牌）
- [x] 接收状态栏与「允许连接 / 自动接收」独立开关
- [x] Windows 托盘（关闭仅隐藏、会话继续、单实例唤醒、退出确认）
